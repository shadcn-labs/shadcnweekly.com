### [pdfcn: shadcn/ui for Document Generation](https://x.com/shadcnlabs/status/2104840500847263794)

Shadcn Labs released pdfcn, an open-source tool for building PDF layouts using UI component patterns. Powered by Takumi and Forme, it supports over 10 themes and 40 pre-built blocks including invoices, reports, and contracts.

It integrates directly with the shadcn/ui workflow via a single command, allowing developers to configure and style document templates with familiar token-driven setups.

---

### [audiocn: Modular Audio Primitives for React](https://audiocn.dev)

Built by OrcDev and fortysevenfx, audiocn brings specialized audio primitives into the shadcn ecosystem. The library provides level meters, frequency visualizers, faders, knobs, channel strips, sound pads, and full mixer layouts.

Components are distributed as copy-paste source files adhering to the shadcn CLI workflow, providing full access to internal styling and mechanics.

---

### [cn: High-Performance Tailwind Class Merging](https://github.com/shadcn-ui/cn)

The shadcn-ui team introduced `cn`, a dedicated engine designed to replace `clsx` and `tailwind-merge`. Retaining identical API signatures for complete backward compatibility, the rewrite benchmarks up to 30× faster at resolving conflicting Tailwind CSS classes.

---

### [DS Manager: Visual Design System Canvas](https://x.com/matsugfx/status/2104892014890254470)

DS Manager launched as an interactive design system canvas for shadcn/ui. It allows developers to define tokens and variants visually, audit components live, and generate customized registries or export configurations directly into projects.

---

## Official Registry Directory Expansions

The official shadcn/ui registry directory welcomed over thirty community registries targeting niche interface requirements.

- **[@gauge-ui](https://www.gauge-ui.dev)** SVG gauge primitives for React featuring arcs, zones, ticks, needles, and spring or tween animation options.
- **[@pastaui](https://pastaui.com)** Interface components dedicated to AI workflows, handling tool calls, approval flows, conversations, and background executions.
- **[@sureui](https://sureui.com)** Open-source confirmation patterns including undo actions, hold-to-confirm, and typed validation components.
- **[@videocn](https://videocn.dev)** A full-featured video player supporting HLS, DASH, live streams, and keyboard shortcuts styled using shadcn tokens.
- **[@tablecn](https://table-cn.vercel.app)** Data table and filter builder blocks with search, pagination, and URL-synchronized filters across Radix and Base UI.
- **[@json-view-cn](https://json-view-cn.vercel.app)** A syntax-highlighted, collapsible JSON tree viewer component built on Base UI primitives.
