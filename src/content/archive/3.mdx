### [shadcn-ui/lint: Agent-First Design System Linter](https://github.com/shadcn-ui/lint)

The shadcn team released `shadcn-ui/lint`, an agent-first linter designed to enforce Tailwind CSS and design system consistency across projects.

The tool resolves components through application TypeScript paths and package exports, enabling teams sharing a centralized UI library across multiple apps to keep component definitions synchronized and clean automatically.

---

### [Clerk: Direct Installation via shadcn CLI](https://clerk.com/docs/guides/development/shadcn-cli)

Clerk launched its official shadcn/ui registry, enabling developers to install authentication components and complete user management configurations using standard shadcn CLI workflows.

The setup bypasses manual boilerplate, pulling configured auth blocks and elements directly into the codebase with local styling intact.

---

### [Message: Conversational Primitives for Chat and Agents](https://ui.shadcn.com/docs/components/base/message)

shadcn/ui introduced the Message component designed specifically for conversation flows and AI interfaces. The primitive coordinates avatars, alignments, headers, and footers around an adaptive message surface.

---

## Official Registry Directory Expansions

The official shadcn/ui registry directory added new specialized community components this week.

- **[@3d-viewer](https://shadcn-3d-viewer.vercel.app)** A composable 3D model viewer with inspection, animation playback, multiple cameras, and screenshots.
- **[@docscn](https://docscn.dev)** Documentation layouts, sidebars, search, and MDX components built as a drop-in replacement on Fumadocs Core.
- **[@uploadcn](https://uploadcn.dev)** Production file upload primitives featuring dropzones, queues, resumable S3/R2 uploads, and 58 UI blocks.
- **[@keyframery](https://keyframery.com)** A lightweight motion layer animating dialogs, sheets, and tabs via a single component alongside list and card helpers.
- **[@colorshot](https://orshot.com/open-source/colorshot)** Color and gradient picker supporting linear, radial, and conic gradients, OKLCH, and eyedroppers themed by tokens.
- **[@harshj](https://shadcn-transfer-list-d4gb-two.vercel.app)** A dual-listbox transfer list with search, check-all, and keyboard controls for Radix and Base UI.
