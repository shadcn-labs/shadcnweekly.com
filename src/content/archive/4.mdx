### [AI Elements: Agentic UI Patterns](https://ui.shadcn.com/docs/ai-elements)

shadcn/ui introduced AI Elements, a curated collection of component patterns created specifically for building conversational and agentic interfaces.

Each pattern is composed from standard shadcn/ui primitives designed to be copied directly into codebases, standardizing interfaces for agent tool calls, planning, sources, and step restoration.

---

### [Trace: Observability Primitive for Agent Activity](https://x.com/shadcn/status/2110410655165779985)

shadcn released Trace, a dedicated primitive designed to unify agent activity displays under one abstraction. It represents reasoning traces, tool executions, task queues, chains of thought, and subagent routines.

Trace models agent progress as a list of status lines with support for expandable details, links, and nested execution steps.

---

### [Chatbot Template: AI SDK Agent Starter](https://github.com/shadcn-ui/chatbot-template)

The shadcn team published an official minimal chatbot template built with Next.js, Vercel AI SDK, shadcn/ui, shadcn/react, and shadcn/typeset.

Designed to run on the Vercel AI Gateway, the starter serves as a clean starting point for streaming conversational interfaces with typographic defaults and state management built in.

## Official Registry Directory Expansions

The official shadcn/ui registry directory added new specialized community components and domain toolkits this week.

- **[@babelize](https://elements.babelize.co)** Open-source localization components including language switchers, relative-time formatters, and translation widgets.
- **[@liquikit](https://liquikit.dev)** Liquid glass primitives with physically based refraction built on Base UI that work across modern browsers.
- **[@audio-ui](https://www.audio-ui.dev)** Accessible audio controls including knobs, faders, XY pads, waveforms, and sequencers on headless primitives.
- **[@bevel](https://bevel-ui.vercel.app)** Tactile skeuomorphic components like guarded switches, split-flap boards, and motorized faders on Tailwind v4.
- **[@dualkit](https://dualkit.dev)** Bilingual Arabic and English components featuring RTL layouts, Gulf currency formats, and Hijri calendar support.
- **[@organui](https://organui.com)** Domain components for healthcare and life sciences featuring 3D organ viewers, ECG traces, and lab result trackers.
