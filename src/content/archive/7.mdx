### [@afterglowui: Glass Sidebars & Liquid Controls](https://afterglowui.vercel.app)

The first new entry in the official shadcn registry directory this week, @afterglowui ships glass sidebars, liquid controls and animated icons built with Tailwind CSS and shadcn/ui.

### [shadcn: Opus 5.5 Is the First Model With Taste](https://x.com/shadcn/status/2117856245101019250)

### [shadcn-admin: Admin Dashboard Built With shadcn](https://shadcn-admin.netlify.app/)

lumxss launched shadcn-admin, a management dashboard built with Next.js, shadcn/ui and TanStack Router. The project includes a sidebar, login page, tables and global search.

## 📙 Articles, Tutorials & News

### [How to Use shadcn/ui in React Native Applications](https://www.freecodecamp.org/news/how-to-use-shadcn-ui-in-react-native-applications-full-handbook/)

A handbook by Ajay Patel showing how shadcn/ui and React Native Reusables keep components consistent as React Native apps grow. It walks through the shift from simple files to complex component systems.

## 📦 Projects, Packages & Tools

### [@ding: Spring Physics Toast](https://ding.yusufcengiz.dev)

A toast with spring physics for React. Only one toast is on screen and a new call morphs it in place instead of stacking, with no dependencies.

### [@plopui: Hand-Drawn React UI](https://plopui.com)

Hand-drawn React UI, imperfect on purpose: sticker buttons, washi-tape tags and a marker font, built on accessible native elements (WCAG AA). Installs the @plop-ui/react package plus editable examples and blocks.
