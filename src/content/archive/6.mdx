### [looseleaf: Hand-Drawn React Primitives](https://kevintngo.github.io/looseleaf/)

Kevin Ngo launched looseleaf, an open-source library of 123 accessible React components designed to look like hand-drawn sketches on paper.

The entire library is distributed via a shadcn registry, allowing developers to install whimsical, sketchy buttons, dialogs, sliders, and form elements directly into their projects.

---

### [Chartory: 100 Dependency-Free SVG Charts](https://usechartory.com)

Chartory published an expansive collection of 100 free, MIT-licensed React chart components rendered directly as SVG without third-party chart dependencies.

The catalog includes complex visualizations such as Sankey diagrams, Gantt schedules, calendar heatmaps, and ridgeline plots, each laid out responsively across four viewport sizes.

---

### [Kinematic: Unified Activity Surface for React](https://kinematic.design)

Kinematic introduced an activity component for React that replaces stacking toast notifications with a single interactive surface.

The component smoothly morphs between background file uploads, agent reasoning steps, media playback, audio calls, and countdown timers.

## Official Registry Directory Expansions

The official shadcn/ui registry directory added specialized interaction toolkits, typography systems, and agent-ready UI primitives this week.

- **[@0nlytype](https://thedirectors.agency/ui)** A typographic component library where every control, badge, and sign is composed entirely in words across two typefaces.
- **[@affectui](https://www.affectui.com)** Single-file, dependency-free React components built for AI agent chat, reasoning states, tool calls, and approvals.
- **[@c15t](https://c15t.com)** Cookie consent banners and preference management modals for React, Next.js, and TanStack Start.
- **[@cloudlet](https://cloudlet.dev/toaster)** A toast notification manager whose message stack collapses into a Dynamic Island pill with spring animations.
- **[@drift-ui](https://drift-ui.dev)** Tailwind v4 components often omitted from shadcn/ui, including tag inputs, steppers, tree views, and file dropzones.
- **[@stickies](https://stickies.live/docs)** Composable sticky notes and draggable, pan-and-zoom whiteboard canvases supporting the open Stickies format.
- **[@sudokw](https://gpuixui.sudokw.com)** Source-owned React components that share shadcn's API but render via the GPUix engine instead of the DOM.
