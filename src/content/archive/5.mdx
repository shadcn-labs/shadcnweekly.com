### [shadcn OIDC: OpenID Connect Configuration Registry](https://x.com/shadcn/status/2113499106844778956)

shadcn announced a new official registry dedicated to building OpenID Connect (OIDC) configuration interfaces.

The registry lets developers compose authentication settings by selecting identity providers, form controls, and validation libraries tailored to their application stack.

---

### [snapcn: Remotion Video Registry by shadcn-labs](https://github.com/shadcn-labs/snapcn)

shadcn-labs released snapcn, an official community registry providing Remotion components designed for rendering product demo videos programmatically.

Developers can use the shadcn CLI to install animated text reveals, terminal sessions, device frames, logo stings, and complete scenes directly into React codebases.

---

### [canvas-kit: Infinite Canvas Primitives for React](https://github.com/mblode/canvas-kit)

canvas-kit is an open-source infinite canvas implementation distributed as a shadcn registry.

The package provides pan, zoom, drag, and marquee selection primitives that install directly into your project as editable source files, enabling custom whiteboard and node interfaces without third-party canvas runtimes.

---

## Official Registry Directory Expansions

The official shadcn/ui registry directory added new specialized domain toolkits, media players, and supervisory primitives this week.

- **[@videojs](https://videojs.org/docs/guides/installation/shadcn)** Audio, video, and live streaming player skins from Video.js delivered as editable React and Tailwind CSS source.
- **[@wick-charts](https://wick-charts.eeff.io/integrations/shadcn/)** Smooth realtime canvas charts that handle streaming data while styling with active shadcn theme tokens.
- **[@creance](https://creance.pages.dev)** Supervisory UI components for AI agents featuring approvals, tool call tracking, run timelines, and diff reviews.
- **[@pluginui](https://pluginui.com)** Audio effect and instrument interface controls for web applications and native DAWs powered by the Maru Audio platform.
- **[@twelfth](https://ui.twelfth.ai)** Domain components for retail buying and category managers, including P10–P90 forecast bands and pricing scoreboards.
- **[@notionic](https://notionic.dev)** React Server Component primitives for Notion pages including KaTeX math, Mermaid diagrams, and toggle lists.
