### [medium-zoom for React](https://medium-zoom.francoischalifour.com/react)

medium-zoom adds image zoom functionality to React with keyboard controls and theme‑aware styling. It works in both client and server contexts, respects reduced‑motion preferences, and integrates smoothly with shadcn/ui.

---

### [shadcn UI customization tool](https://ui.shadcn.com/create?preset=b5LEDkyZu&base=base&template=next)

The customization tool lets you select a component library, base color, fonts and generate a tailored shadcn UI starter. It runs via a CLI and outputs a ready‑to‑use project, making it easy to bootstrap new applications.

## New shadcn UI registries

Several new official registries were added this week, expanding component coverage for developers.

- **[@goodui](https://goodui.dev)** Animated components and app blocks for shadcn with 132 free components and 39 blocks under MIT.
- **[@keyline-ui](https://keyline-ui.dev)** Dense interface components built on Base UI, installed as source and released under MIT.
- **[@svg-scroll-draw](https://svg-scroll-draw.vercel.app/blocks)** Scroll‑animation blocks including signature draws, counters and video scrubbing built on a dependency‑free library.
